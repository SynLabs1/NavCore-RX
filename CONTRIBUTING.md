# Contributing

NavCore RX is currently in pre-launch development.

Useful contributions include:

- Documentation improvements
- Example application ideas
- Wiring guide improvements
- Firmware structure feedback
- Bug reports from testing
- Application requests for rovers, boats, hovercrafts, and custom vehicles

Please open an issue with:

- Your application type
- Hardware setup
- What you are trying to build
- Relevant wiring or configuration details
