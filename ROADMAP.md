# NavCore RX Roadmap

NavCore RX is an open vehicle and robotics controller platform designed to provide reusable hardware and firmware foundations for vehicle and robotics projects.

---

# Current Status

✅ Hardware prototype developed

✅ GPS integration operational

✅ IMU integration operational

✅ Long-range telemetry operational

✅ Servo and ESC control operational

✅ Reference bait boat application operational

✅ Documentation published

✅ Public website launched

✅ Community feedback collection in progress

# Phase 4 — Open Source Release

Status: Planned

Following launch, the project will begin releasing additional development resources.

Planned releases include:

- Complete bait boat reference application
- Reference firmware source code
- Hardware design source files
- Additional technical documentation
- Development examples

Release timing may depend on validation, production readiness, and available development resources.

---

# Reference Application

Current reference application:

- Bait Boat

The bait boat application serves as the primary demonstration of the platform architecture and development workflow.

Additional applications may be explored in the future based on community interest and available development time.

---

# Open Source Commitment

NavCore RX is being developed as an open-source platform.

Documentation is available today.

Additional source code, hardware design resources, and application examples will be released progressively as the platform matures.
